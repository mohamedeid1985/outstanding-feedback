Owner tools

Report date

Feedback editing. Press Lock editing when you start working on the data: supervisors and delegates can then only read their feedback. Reopen editing lets them edit again. A new Load week reopens it automatically.

Each company card has its own button: Lock editing closes that company for the supervisors, Reopen for supervisors opens it again (they can then press Edit). A company also closes by itself when you change its feedback. Changing the note text or the manager does not close it.

Load a new week. In Excel copy columns NO → Medical/Personnel Manager from the new report and paste here (an optional 7th column “Service type” can say Medical, Personnel…). Rows not in the paste are removed.

Comparison with last week (automatic). Every time you press Load week, the previous list kept by the app is compared with the new one. A line is the same only when both the company name and the manager responsible for it are the same. The result shows inside each company card, in the summary above, and as a “Comparison” sheet in the Finance report you download. You do not need to upload anything.

Optional:

Backups (Excel). Press Backup now. The first time you choose the folder; every time after that you are asked whether to keep the same folder or choose another one. The backup is an Excel file saved in a folder named by the upload date, for example “outstanding 27-10-2026”. It is also saved automatically around Load week when a folder has been chosen (Chrome or Edge). The database also keeps a daily snapshot for 30 days.

Files folder. Paste the link of the online folder (OneDrive, SharePoint or Google Drive) where the reports and backups are kept. The “Files folder” button at the top then opens it in one click. Tip: choose the same folder, synced to your computer, as the Backup folder above so everything lands in one place.

“Ready for review” email (optional). Paste the Power Automate flow URL. Leave it empty to see only the banner.

Access codes

Each person signs in with their email and a personal access code. Press “New code” for a random code, or type your own (at least 8 letters or digits, any case) and press Set. Send the code to that person privately. A random code is shown only once; a new code replaces the old one and signs that person out. Save the table first when you add someone.
